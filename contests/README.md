## 먼저 볼 것: 생성형 AI 조항

공모전마다 다르다. 셋 중 하나다.

1. **금지** — "생성형 AI를 활용하지 않은 순수창작물". 걸리면 수상 취소 + 상금 환수.
   → 서울시치과의사회 불법의료광고 공모전이 여기다. 그래서 접었다.
2. **공개 조건부 허용** — 신청서에 "AI 활용 여부 □활용함" 칸이 있다. 체크하고 범위를 적으면 된다.
   → 대한승강기협회 공모전이 여기였다.
3. **명시 없음** — 무역의 날이 여기다. 저작권 동의서에 "타 공모전에 출품하지 않은 본인의
   순수 창작물", "타인의 창작물 도용 금지"만 있고 AI 조항은 없다.

**공고문을 끝까지 읽기 전에는 아무것도 쓰지 않는다.** 슬로건 한 줄 쓰는 데 10분이고
공고문 읽는 데 5분인데, 순서를 바꿨다가 한 번 버렸다.
