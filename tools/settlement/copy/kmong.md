# 크몽 서비스 등록 문구

> **실제 등록 화면 기준으로 다시 정리했다.** 앞서 적었던 "노하우·콘텐츠 >
> 자료·템플릿"은 크몽 판매자 가이드 문서의 내부 분류일 뿐 실제 선택지가 아니다.
>
> 카테고리는 **IT·프로그래밍 > 완성형 프로그램 스토어**.
>
> **자동발송은 없다.** 양식에 작업 기간과 수정 횟수가 있고 파일 업로드 칸은
> 이미지·동영상뿐이다. 주문이 오면 메시지로 ZIP을 직접 보낸다. 주문당 2분이고,
> 첫 고객에게는 어느 마켓을 쓰는지 물어 컬럼을 맞춰줄 수 있으니 초기에는 오히려 낫다.
>
> 입력 제한: 서비스 설명 100자 이상, 서비스 제공 절차 50자 이상,
> 의뢰인 준비사항 50자 이상. 부등호와 백틱은 쓸 수 없다.

## 카테고리

```
IT·프로그래밍 > 완성형 프로그램 스토어
```

## 서비스 제목

```
오픈마켓 정산서 손익 분석 도구
```

## 주요 특징 (선택형)

```
기술 수준   : 중급 이상 (선택지 중 가장 가까운 것)
팀 규모     : 1인
상주 여부   : 비상주
```

## 서비스 제공 절차 (50자 이상)

```
1. 결제하시면 메시지로 압축 파일을 보내드립니다.
   자동 발송이 아니라 제가 직접 보내는 거라, 늦어도 그날 안에는 보내드립니다.

2. 압축을 풀고 정산엑스레이.html 을 더블클릭하면 브라우저에서 바로 열립니다.
   설치하실 건 없습니다.

3. 처음 열면 예시 데이터가 들어 있어서 어떻게 돌아가는지 먼저 보실 수 있습니다.
   같이 넣어드린 예시 정산 파일로 연습해보셔도 됩니다.

4. 익숙해지시면 실제 정산 파일을 끌어다 놓으세요.
   스마트스토어와 쿠팡을 함께 쓰시면 두 파일을 한꺼번에 넣으셔도 됩니다.
   상품별로 합쳐서 봅니다.

   매입원가는 엑셀 원가표에서 상품명과 원가 두 칸을 긁어 붙여넣으시면
   이름을 맞춰 한 번에 들어갑니다. 품목이 많아도 한 번에 끝납니다.

5. 컬럼이 안 잡히거나 숫자가 이상하면 메시지 주세요.
   쓰시는 마켓 양식에 맞춰 조정해서 다시 보내드립니다. 추가 비용은 없습니다.
```

```

11번가나 지마켓도 됩니다.

그 달 광고비 총액. 광고 관리 화면의 그 달 집행액 합계면 됩니다.

파일을 저한테 보내실 필요는 없습니다. 도구가 사장님 기기 안에서만 돌아갑니다.
```

## 작업 전 요청사항

필수 답변을 끌 수 없다면 질문은 **하나만** 넣는다. 짧을수록 좋다.
결제 직전에 읽는 글이라 길면 그 자체가 장벽이 된다.

```
어느 마켓을 쓰시나요?

스마트스토어, 쿠팡처럼 마켓 이름만 적어주시면 됩니다.
그 양식에 맞는지 확인해서 보내드리려고 여쭙습니다.
```

객관식을 고를 수 있으면 그쪽이 낫다. 한 번 누르면 끝이라 이탈이 적다.

```
스마트스토어
쿠팡
11번가
지마켓
그 외
```

품목 수를 묻는 질문은 넣지 않는다. 필수 질문이 둘이면 이탈이 두 배가 되고,
품목 수는 안 물어봐도 파일 보낼 때 대화로 알 수 있다.
