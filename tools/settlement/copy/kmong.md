> **실제 등록 화면 기준으로 다시 정리했다.** 앞서 적었던 "노하우·콘텐츠 >
> 자료·템플릿"은 크몽 판매자 가이드 문서의 내부 분류일 뿐 실제 선택지가 아니다.
>
> 카테고리는 **IT·프로그래밍 > 완성형 프로그램 스토어**.
>
> **자동발송은 없다.** 양식에 작업 기간과 수정 횟수가 있고 파일 업로드 칸은
> 이미지·동영상뿐이다. 주문이 오면 메시지로 ZIP을 직접 보낸다. 주문당 2분이고,
> 첫 고객에게는 어느 마켓을 쓰는지 물어 컬럼을 맞춰줄 수 있으니 초기에는 오히려 낫다.
>
> 입력 제한: 서비스 설명 100자 이상, 서비스 제공 절차 50자 이상,
> 의뢰인 준비사항 50자 이상. 부등호와 백틱은 쓸 수 없다.

```

여기서 매입 원가 331만원과 광고비 45만원을 더 빼야 진짜 남은 돈이 나옵니다.
192만원. 통장에 찍힌 금액의 33.8%입니다.

그런데 진짜 문제는 따로 있었습니다.

유기농 아몬드 1kg은 한 달에 26,167원 손해.
실리콘 주방 집게는 12,355원 손해.

원가가 조금 오르거나 광고비가 붙으면 마진은 소리 없이 음수로 넘어갑니다.

무료 마진 계산기랑 뭐가 다른가요

계산하는 시점도, 대상도, 규모도 다릅니다.


정산 파일이 지저분해도 읽습니다

마켓마다 정산 파일 생긴 게 다 다릅니다.
컬럼 이름을 고정해두면 다른 마켓에서 바로 깨지기 때문에,
까다로운 경우를 하나씩 붙잡고 만들었습니다.

파일 맨 위에 제목이나 조회기간 줄이 붙어 있어도 진짜 헤더를 찾아냅니다.

수수료 부호도 마켓마다 다릅니다. 스마트스토어는 양수로, 쿠팡은 음수로

39,900 같은 숫자가 글자로 저장돼 있어도 읽고,
괄호로 묶인 음수나 원화 기호가 붙어 있어도 읽습니다.

이 네 숫자를 정확히 꺼내오는 일이었습니다.


이런 건 못 합니다

사실대로 적어둡니다. 사고 나서 실망하시는 것보다 낫습니다.

세무 신고용이 아닙니다. 부가세와 배송비와 재고 평가는 계산에 안 넣었습니다.
손익을 빨리 파악하는 용도로 봐주세요.

매입원가는 직접 넣으셔야 합니다. 정산 파일에 없는 정보라

여러 마켓을 합쳐서 보는 기능은 아직 없습니다. 파일 하나씩 봅니다.

마켓이 정산 양식을 바꾸면 컬럼을 다시 지정하셔야 할 수도 있습니다.
화면에서 바로 바꿀 수 있게 해뒀고, 막히시면 메시지 주시면 맞춰드립니다.


마지막으로

파일을 넣는 순간부터 계산이 끝날 때까지 전부 사장님 브라우저 안에서 처리됩니다.
못 믿으시겠으면 인터넷을 끄고 써보세요. 똑같이 돌아갑니다.
```

```
맥에서도 되나요?

됩니다. 크롬이나 사파리, 엣지 같은 브라우저만 있으면 운영체제와 상관없이 열립니다.
윈도우, 맥 둘 다 확인했습니다.
```

### 원가를 매번 다시 입력해야 하나요?

```
원가를 매번 다시 입력해야 하나요?

아니요. 한 번 넣으면 쓰시던 브라우저에 저장돼서 다음에 열 때 그대로 있습니다.
다음 달부터는 정산 파일만 새로 넣고 광고비만 고치시면 1분이면 끝납니다.
다만 같은 브라우저에서만 유지되니, 컴퓨터를 바꾸시면 다시 넣으셔야 합니다.
```

정산 파일이 몇 천 줄인데 괜찮나요?

괜찮습니다. 행수 제한이 없습니다.
파일 개수도 제한 없어서 월별로 여러 개 돌려보셔도 됩니다.

```
결과를 엑셀로 옮길 수 있나요?

따로 내보내기 하실 필요 없습니다.
```

### 계산이 정확한지 어떻게 믿나요?

```
계산이 정확한지 어떻게 믿나요?

계산 부분을 화면과 분리해두고, 별도로 계산한 정답과 대조하는 검증을 거쳐서 내보냅니다.
스마트스토어형과 쿠팡형 두 가지 정산 파일에서 상품별 수량, 매출, 수수료, 원가,
순이익이 전부 맞아떨어지는지 확인합니다.
그래도 첫 달은 기존에 쓰시던 방식과 나란히 놓고 비교해보시길 권합니다.
```

### 여러 마켓을 합쳐서 볼 수 있나요?

```
여러 마켓을 합쳐서 볼 수 있나요?

지금은 파일 하나씩 봅니다. 스마트스토어와 쿠팡을 각각 넣어서 따로 보시는 방식입니다.
합산 기능은 준비 중이고, 나오면 추가 비용 없이 보내드립니다.
```

### 제가 쓰는 마켓 정산 파일도 읽나요?

제가 쓰는 마켓 정산 파일도 읽나요?

다음 달에도 그대로 쓸 수 있나요?

## 작업 전 요청사항

첫 번째는 넣는다. 두 번째는 선택.

### 1. 사용 마켓 (권장)

```
어느 마켓의 정산 파일을 보실 예정인지 알려주세요.

스마트스토어, 쿠팡, 11번가, 지마켓, 그 외 어디든 괜찮습니다.
여러 곳 쓰시면 전부 적어주셔도 됩니다.

미리 알려주시면 그 마켓 양식에 맞는지 확인해서 보내드릴 수 있습니다.
정산 파일을 보내주실 필요는 없고, 마켓 이름만 적어주시면 됩니다.
```

### 2. 품목 수 (선택)

```
판매 중인 품목이 대략 몇 개인지 알려주시면 좋습니다.

정확하지 않아도 괜찮습니다. 열 개 안쪽인지, 백 개쯤인지 정도면 충분합니다.
품목이 많으시면 원가를 어떤 순서로 넣는 게 편한지 같이 안내드리겠습니다.
```

## 결제 후 안내 메시지

```
구매해 주셔서 감사합니다.

보내드린 압축 파일을 내려받아 풀어주세요.
"정산엑스레이.html"을 더블클릭하면 브라우저에서 바로 열립니다.
설치할 것은 없습니다.

압축 안에 예시 정산 파일이 들어있어, 실제 파일 넣기 전에
연습해보실 수 있습니다.

처음 여시면 예시 데이터가 들어있어 어떻게 동작하는지 먼저 보실 수 있습니다.
확인하신 뒤 "파일 선택"으로 실제 정산 파일을 넣으시면 됩니다.

첫 실행 순서
  1. 정산 엑셀을 끌어다 놓기
  2. 컬럼이 맞게 잡혔는지 확인 (틀리면 선택해서 변경)
  3. 상품별 매입원가 입력 — 한 번만 넣으면 기억됩니다
  4. 그 달 광고비 총액 입력

컬럼이 자동으로 안 잡히거나 숫자가 이상하면 메시지 주세요.
정산 양식은 마켓마다 달라서, 알려주시면 바로 맞춰 드립니다.
```

## 미리보기 이미지 (최소 5장, 본문 4장 이상)

1. 표지 — 헤드라인 "통장에 5,692,369원. 실제로 번 돈은 1,925,069원"
2. 영수증 — 매출에서 순이익까지 차감 과정
3. 적자 상품 — 손해 보는 상품 2개가 빨갛게 잡힌 화면
4. 상품별 손익 차트 — 흑자/적자가 갈리는 막대
5. 상세 표 — 상품별 수량·매출·수수료·원가·순이익


## 등록 전에 확인할 것 — 통신판매업 신고

```
디지털 콘텐츠 판매도 통신판매업 신고 대상에 들어간다.

크몽은 사업자 등록·통신판매업 신고 전에도 개인 전문가로 판매를 시작할
수 있게 해두었지만, 거래 횟수·규모 기준을 넘으면 신고 후에 판매해야 한다.
신고 대상인데 신고하지 않으면 3천만 원 이하의 벌금이 있을 수 있다.

기준을 넘는지는 거래 횟수와 규모로 판단하므로, 시작 전에 정부24나
공정거래위원회 안내로 본인 상황을 확인할 것. 세금 문제는 세무사에게
확인하는 편이 안전하다.

이건 법률 자문이 아니라, 알고는 시작하시라는 메모다.
```
