# 크몽 서비스 등록 문구

> 크몽은 **용역(서비스) 마켓**이다. 전자책 카테고리는 PDF 20~30쪽을 전제로 해서
> 우리 제품(도구 파일)과 맞지 않는다. 그래서 **업무자동화** 카테고리에
> "도구 제공 + 내 파일에 맞춤 세팅"이라는 서비스로 올린다.
> 이 구성은 컬럼 이름이 안 맞을 위험도 같이 해결한다.

## 서비스 제목

```
스마트스토어·쿠팡 정산서에서 팔수록 손해인 상품 찾아드립니다
```

대안:
```
정산 엑셀 한 장으로 상품별 진짜 순이익 뽑아드립니다
```

## 카테고리

업무자동화 > 엑셀·데이터 자동화

## 서비스 설명

### 이런 분께 필요합니다

```
· 정산금은 들어오는데 정작 얼마가 남는지 모르겠다
· 상품이 늘어날수록 어떤 게 돈이 되는지 감이 안 온다
· 광고비까지 넣어서 계산하면 남는 게 맞나 싶다
· 매달 엑셀을 붙잡고 정산서를 정리하다 포기했다
```

### 정산서는 얼마가 남는지 알려주지 않습니다

```
정산서가 알려주는 건 "얼마가 입금되는지"까지입니다.
그 돈에서 원가와 광고비를 빼면 실제로 얼마가 남는지,
어떤 상품이 돈을 잃고 있는지는 알려주지 않습니다.

예시로 만든 한 달 정산 데이터로 보면 이렇습니다.

  매출              6,112,500원
  − 수수료             420,131원
  ─────────────────────────────
  = 정산 입금액      5,692,369원   ← 통장에 찍히는 돈
  − 매입 원가        3,317,300원
  − 광고비             450,000원
  ─────────────────────────────
  = 실제 순이익      1,925,069원   ← 입금액의 33.8%

전체 마진율 31.5%면 나쁘지 않아 보입니다.
그런데 상품별로 쪼개보면 이 안에 팔수록 손해인 상품이 2개 있었습니다.

  유기농 아몬드 1kg      −26,167원   (−6.0%)
  실리콘 주방 집게 2p    −12,355원   (−6.3%)

원가가 오르거나 광고비가 붙으면 마진은 조용히 음수로 넘어갑니다.
총액만 봐서는 이 두 상품이 다른 상품이 번 돈을 갉아먹고 있다는 걸
알 수 없습니다.
```

### 무료 마진 계산기와 무엇이 다른가요

```
무료 계산기는 상품 하나의 "앞으로의 예상 마진"을 손으로 입력해 계산합니다.
이 도구는 "이미 지나간 실제 정산 파일" 수백~수천 행을 통째로 읽어,
반품과 광고비까지 반영한 사후 손익을 상품별로 냅니다.

계산하는 시점도, 대상도 다릅니다.
```

### 정산 파일이 지저분해도 읽습니다

```
마켓마다 정산 파일 모양이 다릅니다. 컬럼 이름을 고정해두면 바로 깨지기
때문에, 까다로운 경우를 하나씩 처리하도록 만들었습니다.

· 파일 위에 제목·조회기간 줄이 붙어 있어도 진짜 헤더를 찾습니다
· 수수료 부호가 마켓마다 달라도 (스마트스토어는 +, 쿠팡은 −)
  매출 부호와 대조해 자동으로 맞춥니다
· 결제수수료·판매수수료·쿠폰분담금이 따로 있으면 모두 더합니다
· 반품은 음수 행으로 인식해 매출·수수료·원가에서 함께 뺍니다
· 39,900 / (1,234) / △500 / ₩12,000 처럼 글자로 저장된 숫자도 읽습니다
· 맨 아래 합계·소계 줄을 상품으로 세지 않습니다
```

### 정산 파일을 보내지 않으셔도 됩니다

```
STANDARD는 도구만 받아 직접 쓰시는 구성입니다.
도구에는 서버가 없어서 정산 파일이 어디로도 전송되지 않습니다.
계산은 전부 브라우저 안에서 끝나고, 인터넷을 끊어도 동작합니다.

정산 파일에는 한 달 매출이 전부 담겨 있습니다.
그게 불편하신 분이 많아서 이렇게 만들었습니다.

DELUXE 이상에서 맞춤 세팅을 원하시는 경우에만 파일이 필요하고,
그때도 상품명과 금액을 지운 파일로 진행하실 수 있습니다.
```

### 진행 방식

```
STANDARD
  1. 결제해 주시면 도구 파일과 가이드를 보내드립니다
  2. 파일을 열어 정산 엑셀을 끌어다 놓으면 끝입니다

DELUXE / PREMIUM
  1. 결제 후 정산 파일 샘플을 보내주세요 (금액은 지우셔도 됩니다)
  2. 컬럼 매핑을 맞춰 세팅한 도구를 보내드립니다
  3. 원가표를 함께 만들고, 첫 리포트를 뽑아 확인해 드립니다
```

```
· 마켓이 정산 양식을 바꾸면 컬럼을 다시 지정해야 할 수 있습니다.
  화면에서 바로 바꿀 수 있게 해뒀습니다.
```

## FAQ

```
Q. 엑셀을 잘 몰라도 쓸 수 있나요?
A. 마켓에서 받은 정산 파일을 그대로 끌어다 놓으면 됩니다.
   수식을 쓰거나 표를 만들 필요는 없습니다. 직접 넣으실 값은
   상품별 매입원가와 그 달 광고비 총액뿐입니다.

Q. 정산 파일이 어디로 전송되나요?
A. 전송되지 않습니다. 서버가 없어서 보낼 곳도 없습니다.
   인터넷을 끊고 써보셔도 똑같이 동작합니다.

Q. 여러 마켓을 함께 볼 수 있나요?
A. 현재는 파일 하나씩 분석합니다. 스마트스토어와 쿠팡을 각각 넣어
   따로 보는 방식입니다. 합산 기능은 준비 중입니다.

Q. 원가를 매번 다시 입력해야 하나요?
A. 아니요. 한 번 넣으면 쓰시던 브라우저에 저장됩니다.
   다만 같은 브라우저에서만 유지되니 컴퓨터를 바꾸면 다시 넣으셔야 합니다.

Q. 결과를 엑셀로 옮길 수 있나요?
A. 표 복사 버튼을 누르면 엑셀·구글 시트에 바로 붙여넣을 수 있습니다.

Q. 계산이 정확한지 어떻게 믿나요?
A. 계산 로직은 화면과 분리해 두고, 별도로 계산한 정답과 대조하는
   검증을 거칩니다. 스마트스토어형·쿠팡형 두 가지 정산 파일에서
   상품별 수량·매출·수수료·원가·순이익이 모두 일치하는지 확인합니다.
   그래도 첫 달은 기존 방식과 나란히 놓고 비교해보시길 권합니다.

Q. 맥에서도 되나요?
A. 됩니다. 크롬·사파리·엣지 등 브라우저만 있으면 운영체제와 무관합니다.
```

```

첨부된 파일을 내려받아 더블클릭하면 브라우저에서 바로 열립니다.
설치할 것은 없습니다.

처음 여시면 예시 데이터가 들어있어 어떻게 동작하는지 먼저 보실 수 있습니다.
확인하신 뒤 "파일 선택"으로 실제 정산 파일을 넣으시면 됩니다.

첫 실행 순서
  1. 정산 엑셀을 끌어다 놓기
  2. 컬럼이 맞게 잡혔는지 확인 (틀리면 선택해서 변경)
  3. 상품별 매입원가 입력 — 한 번만 넣으면 기억됩니다
  4. 그 달 광고비 총액 입력

컬럼이 자동으로 안 잡히거나 숫자가 이상하면 메시지 주세요.
정산 양식은 마켓마다 달라서, 알려주시면 바로 맞춰 드립니다.
```
