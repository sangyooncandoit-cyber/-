# 카페·커뮤니티 홍보글

> **올리기 전에 그 카페 규칙부터 읽는다.** 셀러 카페는 홍보 규정이 엄격한 곳이
> 많고, 어기면 강퇴당해 다시 못 들어간다. 유입 경로 하나를 통째로 잃는다.
> 규칙에 "홍보 금지"가 있으면 운영자에게 먼저 쪽지로 물어본다.
>
> **유료 판매 얘기는 넣지 않는다.** 무료 도구만 소개하고 판매는 도구 안의
> 잠금 화면이 한다. 규칙에 걸릴 위험이 낮고 전환도 더 잘 된다.
>
> **셀러인 척하지 않는다.** 만든 사람 입장에서 쓴다. 카페 사람들은 가짜 동료를
> 금방 알아본다. 솔직한 편이 오히려 먹힌다.

## 등업부터 — 댓글 30개

아프니까 사장이다(cafe.naver.com/jihosoccer123)는 회원 168만의 국내 최대
자영업 커뮤니티다. 그만큼 등업 조건이 있고, 정성스러운 댓글 30개를 요구한다.

숙제로 보면 서른 번 버티는 일이고, 리서치로 보면 서른 번 배우는 일이다.
자영업자들이 매일 뭘 묻는지 서른 번 읽게 된다. 그게 그대로 다음에 고칠
목록이 되고, 나중에 글을 올릴 때 처음 보는 사람이 아니라 댓글 달던
사람이 된다.

카페 검색에서 우리가 실제로 아는 말들을 찾는다.

```
정산
수수료
마진
매입 원가
스마트스토어 정산
쿠팡 정산
```

거기 올라온 질문에 아는 만큼만 답한다. 모르면 넘어간다.

**좋은 댓글의 조건은 하나다. 그 글을 읽었다는 게 드러나야 한다.**
"좋은 정보 감사합니다"는 서른 개를 달아도 등업이 안 된다. 그런 건 걸러진다.

**링크는 넣지 않는다. 도구 얘기도 꺼내지 않는다.** 등업 전에 홍보로 잡히면
거기서 끝이고, 그 카페는 다시 못 쓴다. 지금은 사람을 알아가는 단계다.

하루 서넛씩 일주일이면 채워진다. 하루에 몰아서 달면 그것도 눈에 띈다.

### 댓글 예시 — 그대로 쓰지 말고 모양만 본다

수수료 질문에

```
쿠팡은 카테고리별로 판매수수료가 달라서 같은 매출이어도 차이가 꽤 납니다.
식품 쪽이 12% 정도였던 걸로 기억해요. 혹시 로켓그로스 쓰시면 그 비용이
또 따로 붙습니다.
```

마진 질문에

```
저도 처음엔 정산 입금액을 남은 돈으로 봤는데, 거기서 매입 원가랑 광고비를
더 빼야 실제로 남는 게 나오더라고요. 광고비를 상품별로 나눠서 보면
생각도 못 한 상품이 적자로 나옵니다.
```

엑셀 질문에

```
피벗으로 상품명 행에 두고 매출이랑 수수료 합계 잡으면 편한데,
맨 아래 합계 줄이 상품 하나로 잡히는 걸 조심하셔야 해요.
저는 그것 때문에 한참 숫자가 안 맞았습니다.
```

세 개 다 아는 것을 말하고, 파는 얘기는 없다. 그게 핵심이다.
