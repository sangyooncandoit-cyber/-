# 카페·커뮤니티 홍보글

> **올리기 전에 그 카페 규칙부터 읽는다.** 셀러 카페는 홍보 규정이 엄격한 곳이
> 많고, 어기면 강퇴당해 다시 못 들어간다. 유입 경로 하나를 통째로 잃는다.
> 규칙에 "홍보 금지"가 있으면 운영자에게 먼저 쪽지로 물어본다.
>
> **유료 판매 얘기는 넣지 않는다.** 무료 도구만 소개하고 판매는 도구 안의
> 잠금 화면이 한다. 규칙에 걸릴 위험이 낮고 전환도 더 잘 된다.
>
> **셀러인 척하지 않는다.** 만든 사람 입장에서 쓴다. 카페 사람들은 가짜 동료를
> 금방 알아본다. 솔직한 편이 오히려 먹힌다.

## 등업부터 — 댓글 30개

아프니까 사장이다(cafe.naver.com/jihosoccer123)는 회원 168만의 국내 최대
자영업 커뮤니티다. 그만큼 등업 조건이 있고, 정성스러운 댓글 30개를 요구한다.

숙제로 보면 서른 번 버티는 일이고, 리서치로 보면 서른 번 배우는 일이다.
자영업자들이 매일 뭘 묻는지 서른 번 읽게 된다. 그게 그대로 다음에 고칠
목록이 되고, 나중에 글을 올릴 때 처음 보는 사람이 아니라 댓글 달던
사람이 된다.

카페 검색에서 우리가 실제로 아는 말들을 찾는다.

```
정산
수수료
마진
매입 원가
스마트스토어 정산
쿠팡 정산
```

거기 올라온 질문에 아는 만큼만 답한다. 모르면 넘어간다.

**좋은 댓글의 조건은 하나다. 그 글을 읽었다는 게 드러나야 한다.**
"좋은 정보 감사합니다"는 서른 개를 달아도 등업이 안 된다. 그런 건 걸러진다.

**링크는 넣지 않는다. 도구 얘기도 꺼내지 않는다.** 등업 전에 홍보로 잡히면
거기서 끝이고, 그 카페는 다시 못 쓴다. 지금은 사람을 알아가는 단계다.

하루 서넛씩 일주일이면 채워진다. 하루에 몰아서 달면 그것도 눈에 띈다.

### 댓글 예시 — 그대로 쓰지 말고 모양만 본다

같은 문장을 돌려 쓰면 티가 난다. 아래는 어떤 글에 무엇을 말할 수 있는지
보여주는 것이지 붙여넣을 문장이 아니다. 한 줄이라도 그 글에 맞게 고친다.

전부 아는 것을 말하고 파는 얘기는 없다. 그게 핵심이다.

**"이번 달 얼마 남았는지 모르겠다" 같은 글에**

```
저도 그게 제일 헷갈렸어요. 정산 입금액은 플랫폼 수수료까지만 빠진
금액이라, 거기서 매입 원가랑 광고비를 더 빼야 실제로 남는 게 나오더라고요.
총액으로 보면 괜찮아 보이는데 상품별로 쪼개면 얘기가 달라지는 경우가 많습니다.
```

**쿠팡 수수료를 묻는 글에**

```
쿠팡은 카테고리마다 판매수수료가 달라서 같은 매출이어도 차이가 납니다.
식품이 12% 정도, 생활용품이 10~13% 정도로 알고 있어요. 로켓그로스
쓰시면 그 비용이 또 따로 붙어서 거기까지 넣고 보셔야 합니다.
```

**스마트스토어 수수료를 묻는 글에**

```
스마트스토어는 두 개로 나뉘더라고요. 주문관리수수료가 영세면 1.98%,
일반이면 3.63% 정도고, 네이버쇼핑 타고 들어온 주문엔 연동수수료 2.73%가
또 붙습니다. 외부 링크로 들어온 주문은 0.91%라 유입 경로에 따라 차이가 꽤 납니다.
```

**엑셀로 정산 정리하다 막혔다는 글에**

```
피벗으로 상품명을 행에 두고 매출이랑 수수료를 합계로 잡으면 편한데,
맨 아래 합계 줄이 상품 하나로 같이 잡히는 걸 조심하셔야 해요.
저는 그것 때문에 한참 숫자가 안 맞아서 헤맸습니다.
```

**정산 숫자가 안 맞는다는 글에**

```
혹시 수수료가 한 칸이 아니라 여러 칸에 쪼개져 있진 않은지 보세요.
결제수수료, 판매수수료, 쿠폰분담금이 따로 잡혀 있으면 다 더해야 맞습니다.
마켓마다 수수료를 양수로 적는 곳과 음수로 적는 곳이 있어서, 두 파일을
섞어 쓰면 부호 때문에 틀어지기도 하더라고요.
```

**광고비 고민 글에**

```
광고비를 총액으로만 보면 어느 상품이 까먹는지가 안 보이더라고요.
상품별 매출 비중으로 나눠서 붙여보면 생각도 못 한 상품이 적자로 나옵니다.
저는 광고만 껐는데 흑자로 돌아온 상품도 있었습니다.
```

**적자 상품을 찾았는데 어떻게 하냐는 글에**

```
보통 네 가지 중 하나인 것 같아요. 가격을 올리거나, 매입 단가를 다시
협상하거나, 그 상품 광고를 끄거나, 접거나.
광고만 꺼도 흑자로 도는 경우가 생각보다 많습니다.
```

**반품 때문에 계산이 꼬인다는 글에**

```
반품이 음수 행으로 들어와 있으면 그냥 같이 더하면 되는데, 마켓에 따라
별도 시트로 빠져 있는 경우가 있어요. 그거 빼먹으면 매출이 부풀려져서
마진이 실제보다 좋아 보입니다.
```

**초보 셀러가 뭘 봐야 하냐고 묻는 글에**

```
처음엔 매출부터 보게 되는데 저는 상품별 순이익을 먼저 보는 게 낫더라고요.
매출 1등이 이익 1등이 아닌 경우가 꽤 있습니다.
매입 원가만 정리해두시면 그때부터 보이기 시작해요.
```

### 이런 댓글은 세지 않는다

좋은 정보 감사합니다. 잘 보고 갑니다. 저도 공감합니다. 화이팅입니다.

내용이 없으면 서른 개를 달아도 등업이 안 된다. 공감만 하고 싶은 글에는
공감만 달아도 되지만, 그건 서른 개에서 빼고 세는 편이 안전하다.

묻는 쪽으로 단다. 아는 척보다 낫고 대화가 이어진다.

```
건가요? 둘이 기준이 달라서 여쭤봅니다.
```
