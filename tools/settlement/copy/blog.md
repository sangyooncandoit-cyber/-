# 블로그 글

> **카페 글과 목적이 다르다.** 카페는 그날 본 사람에게 닿고 끝나지만, 블로그는
> 검색으로 계속 들어온다. 그래서 광고가 아니라 **검색한 사람이 찾던 답**이어야 한다.
> 도구 얘기 없이 읽어도 쓸모가 있어야 검색에도 잡히고 신뢰도 생긴다.
>
> 네이버 블로그를 권한다. 타겟이 네이버에서 검색하는 셀러들이다.
>
> **한 편을 제대로 쓴다.** 비슷한 글을 대량으로 찍어내면 검색에서 불이익을 받는다.

```

그래서 세 줄에 3,000원씩 = 9,000원이 아니라 3,000원.

이건 논쟁의 여지가 없습니다.

구매자가 결제한 총액을 보세요.

상품 세 개가 각각 12,000원이고 배송비가 3,000원이면

   36,000 + 3,000 = 39,000원

결제 총액이 39,000원이면 배송비 한 번 받은 거예요.
45,000원이면 세 번 받은 거고요.

주문 상세에서 묶음배송번호가 같은지 봐도 됩니다.
번호가 같으면 한 건이에요.


조건부무료가 뭐냐면

기본 배송비랑 별개로 한 번 더요.


근데 진짜 하고 싶은 얘기는 여기부터예요

배송비가 몇 번인지 확인하셨으면 그다음 질문이 남거든요.

그래서 이 배송비, 내 돈인가?

정산 내역 보면 구매자가 낸 배송비가 정산 대상에 들어와 있어요.
입금액에 포함돼서 들어온다는 얘기죠.

그래서 정산서만 보면 배송비가 수입처럼 보입니다.

근데 택배사에 나가는 돈은요?
그건 정산서에 없어요. 통장에서 따로 나갑니다.

   받은 배송비     3,000원
   나간 택배비     2,800원
   남은 것           200원

200원이에요. 3,000원이 아니라.

무료배송 걸어두신 상품은 더 확실하죠.

   받은 배송비         0원
   나간 택배비     2,800원
   남은 것        -2,800원

주문 한 건마다 2,800원씩 나가고 있는 거예요.
한 달에 백 건이면 28만원입니다.


그럼 손익은 어떻게 계산하나

   순이익 = 매출 - 수수료 - 매입원가 - 광고비 - 실제 택배비 + 받은 배송비

받은 배송비는 정산에 이미 들어와 있어서 매출 쪽에 포함돼 있고요,
따로 빼야 하는 건 실제로 나간 택배비예요.

계약 단가가 건당 2,800원이고 그 달 주문이 253건이면 708,400원.
이게 손익에서 빠져야 할 돈입니다.

무료배송 상품이 많은 달엔 이 금액이 꽤 커져요.
상품별로 보면 차이가 더 벌어지고요.
부피 큰 상품, 무료배송 건 상품일수록 많이 나가니까요.


짧게 다시

묶음배송이면 배송비는 한 번.
여러 줄로 보이는 건 표시 방식일 뿐.
확인은 구매자 결제 총액으로.

그리고 배송비는 수입이 아니에요.
```

# 3편 — 할인액

```
일단 산수부터 맞춰봅시다

표에서 "최종 상품별 할인액" 칸을 보세요.

   상품가격        90,000원
   최종 할인액     23,000원
   ─────────────────────────
   총 주문금액     67,000원

90,000 빼기 23,000은 67,000.

산수는 맞습니다.

"할인이 왜 2만 3천이지"예요.
```
