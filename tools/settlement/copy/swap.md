# 크몽 승인 후 교체 목록

> 승인 나면 이 순서대로 하면 된다. 실제로 바꿀 건 두 개뿐이다.

## 심사 중에는 손대지 않는다

**수정하면 심사 대기가 그날부터 다시 시작된다.** 기다린 날이 통째로
날아간다. 승인 알림이 오기 전까지는 가격도 설명도 건드리지 않는다.

1차 카테고리는 승인 후에도 바꿀 수 없다. 바꾸려면 서비스를 새로 등록해야
한다. 지금 IT·프로그래밍으로 잡혀 있고 바꿀 일도 없으니 건드리지 않는다.

승인이 나면 아래 둘을 **한 번에** 고친다. 나눠서 두 번 올리면 재심사도
두 번이다.

**지금 올라가 있는 설명은 실제 제품보다 못하다.** 제출한 뒤에 기능이
늘었기 때문이다. 여러 마켓 합산과 배송비를 못 한다고 적어두었는데 둘 다
된다. 손익분기와 기간 비교도 통째로 빠져 있다. 틀린 말은 아니고 과소
약속이라 손해는 아니지만, 팔 기회를 버리고 있는 것이다.

## 1. 가격 — 49,000원을 39,000원으로

마이크몽 > 내 서비스 > 서비스 관리 > 가격 정보.
STANDARD 금액 칸만 고친다.

```
39000
```

제목(20자)과 설명(60자), 작업 기간 1일, 수정 횟수 3회, 체크박스 세 개 비움.
이건 전부 그대로 둔다.

## 2. 서비스 설명 — 통째로 교체

전체를 지우고 아래를 붙여넣는다. 일부만 고치면 앞뒤가 안 맞는다.

제출본과 달라진 곳은 다섯 군데다.

하나. "무료 마진 계산기랑 뭐가 다른가요" 절이 "연동해서 자동으로 해주는
서비스도 있던데요"로 통째로 바뀌었다. 무료 계산기는 애초에 진짜 경쟁
상대가 아니었다.

둘. 적자 두 개 합계(월 38,522원)와 도구값(39,000원)을 나란히 놓은 문단이
앞쪽에 들어갔다.

셋. 여러 마켓 합산이 된다. 제출본에는 안 된다고 적혀 있다.

넷. 택배비가 계산에 들어갔다. 제출본에는 배송비를 안 넣는다고 적혀 있다.

다섯. 적자 상품의 손익분기 판매가와, 지난달 파일을 같이 넣으면 나오는
기간 비교가 새로 들어갔다.

## 3. 올리고 나서 확인할 것

판매 화면에서 가격이 39,000원으로 보이는가.

설명 안에 "무료 마진 계산기"라는 말이 더는 없는가.

심사 상태가 다시 검수중으로 갔는가. 수정하면 다시 심사를 받는다.
갔으면 그냥 기다린다. 이번에도 중간에 또 건드리면 처음부터다.

## 손대지 않는 것

서비스 제목, 카테고리, 주요 특징, 서비스 제공 절차, 의뢰인 준비사항,
수정 및 재진행 안내, 검색 키워드, 메인·상세 이미지, 전문가 프로필,
자주 묻는 질문, 작업 전 요청사항, 자동응답, 결제 후 안내 메시지.

전부 그대로 둔다. 바뀐 게 없다.

아직 안 올렸으면 그때 그대로 쓰면 된다.

블로그와 카페 글은 값을 언급하지 않아서 고칠 게 없다.
