# 크몽 등록 문구 — 정산 분석 대행

> 파는 물건이 바뀐다. 프로그램을 넘기는 게 아니라 **결과를 만들어
> 넘긴다.** 고객은 정산 파일과 원가만 보내고, 리포트를 받는다.
>
> 왜 바꾸는지는 `plan/대행_방향.md` 에 근거와 함께 적어뒀다.
> 한 줄로 줄이면 — 자동 계산 프로그램은 이미 여러 명이 팔아봤고
> 거의 안 팔렸다(합쳐서 3건). 대행은 아무도 안 하고 있는데,
> 옆 동네 원가계산 대행은 8만원에 46건 팔렸다.
>
> **심사 중인 기존 서비스는 건드리지 않는다.** 이건 별도 등록이다.

## 카테고리 — 등록 화면을 보고 정한다

지난번처럼 추측으로 적지 않는다. 등록 화면에 실제로 뜨는 선택지를
보고 아래 순서로 고른다.

1. 데이터 분석·가공 계열이 있으면 그것
2. 없으면 비즈니스 컨설팅 계열
3. 그것도 없으면 업무 자동화 계열

**1차 카테고리는 등록 후 못 바꾼다.** 기존 서비스가 IT·프로그래밍에
있으니, 이건 다른 데 두는 편이 검색 노출에서 겹치지 않아 낫다.

## 서비스 제목

```
정산 엑셀 보내주시면 상품별 순이익 뽑아 드립니다
```

## 서비스 설명

```
통장에 찍힌 금액 말고, 실제로 남은 돈이 궁금하신 분께.

정산서는 얼마가 입금되는지까지만 알려줍니다.
어떤 상품이 돈을 벌고 있는지는 알려주지 않습니다.

정산 엑셀과 상품별 원가만 보내주시면, 제가 계산해서 리포트로 보내
드립니다. 프로그램을 설치하실 필요도, 엑셀 수식을 만지실 필요도 없습니다.


무엇이 나오나요

상품별 순이익표가 나옵니다.
매출에서 수수료와 원가와 광고비와 택배비를 뺀, 진짜 남은 금액입니다.
많이 남은 순서로 정렬해 드립니다.

적자 상품을 따로 뽑아 드립니다.
전체 마진율이 괜찮아 보여도, 쪼개보면 팔수록 손해인 상품이 섞여 있는
경우가 많습니다. 잘 팔리는 상품이 번 돈에 묻혀서 총액만 보면 안 보입니다.

적자 상품은 얼마에 팔아야 본전인지까지 계산해 드립니다.
원가가 조금 오르거나 광고비가 붙으면 마진은 소리 없이 음수로 넘어갑니다.
그 경계선을 숫자로 알려드립니다.

여러 마켓을 함께 하시면 합산해 드립니다.
스마트스토어와 쿠팡의 정산서를 각각 보내주시면 한 장으로 합칩니다.
같은 상품이 마켓마다 얼마나 다르게 남는지 보입니다.

지난달 파일도 같이 주시면 변화를 비교해 드립니다.
어떤 상품의 마진이 줄고 있는지, 무엇이 반대인지 나옵니다.


어떤 파일을 읽나요

스마트스토어, 쿠팡, 11번가, G마켓, 옥션, 위메프, 티몬의 정산 내역을
읽습니다. 엑셀이든 CSV든 상관없습니다.

컬럼 이름이 마켓마다 다르고 수시로 바뀌는데, 그건 제가 맞춥니다.
정리해서 보내실 필요 없습니다. 받은 그대로 주시면 됩니다.

파일이 여러 개여도 됩니다. 개수 제한 없습니다.


수수료 부가세는 어떻게 하나요

빼지 않습니다. 일부러 그렇게 합니다.

수수료에 붙는 부가세는 사장님이 나중에 돌려받는 매입세액입니다.
그걸 마진표에서 빼면 실제보다 적게 남는 것처럼 보입니다.
이미 낸 돈을 두 번 빼는 셈이거든요.

리포트에는 수수료 본체만 반영합니다.
부가세 포함 금액이 따로 필요하시면 말씀해 주세요. 같이 넣어 드립니다.


프로그램을 사는 것과 뭐가 다른가요

프로그램은 내 파일을 제대로 읽을지 사기 전에 알 수가 없습니다.
컬럼이 안 잡히면 결국 내가 붙잡고 씨름해야 합니다.

이건 그 위험이 저한테 있습니다.
파일을 보내주시면 제가 맞춰서 계산합니다. 안 맞으면 제가 고칩니다.
사장님은 받아보시기만 하면 됩니다.


무엇을 못 하나요

미리 말씀드리는 편이 낫겠습니다.

세무 신고용 자료는 아닙니다. 부가세 신고나 종합소득세에 그대로 쓰실 수
없습니다. 그건 세무사님 영역입니다.

재고 관리는 하지 않습니다. 팔린 것만 봅니다.

상품별 원가를 모르시면 순이익이 안 나옵니다.
매출에서 수수료만 뺀 금액까지는 나오지만, 그건 정산서에도 있는 숫자입니다.
원가를 정리하실 수 있는지 먼저 확인해 주세요.
```

## 서비스 제공 절차

```
1. 주문하시면 메시지로 보내실 파일 목록을 안내해 드립니다.

2. 정산 엑셀과 상품별 원가를 메시지로 보내주세요.
   원가는 양식 없이 상품명과 금액만 적어 주셔도 됩니다.

3. 파일을 열어 컬럼을 맞추고 계산합니다.
   읽히지 않는 항목이 있으면 그 자리에서 여쭤봅니다.

4. 리포트를 PDF와 엑셀 두 가지로 보내 드립니다.
   PDF는 보시는 용도, 엑셀은 직접 만져 보실 용도입니다.

5. 숫자가 이상해 보이는 곳이 있으면 말씀해 주세요.
   어디서 나온 값인지 원본 행을 짚어 드립니다.
```

## 의뢰인 준비사항

```
두 가지만 있으면 됩니다.

하나. 정산 내역 엑셀입니다.
스마트스토어는 판매관리 안의 정산관리에서, 쿠팡은 판매자센터 정산 메뉴에서
받으실 수 있습니다. 기간은 한 달치면 충분합니다.
받은 파일을 손대지 말고 그대로 주세요.

둘. 상품별 매입 원가입니다.
상품명과 개당 원가만 적어 주시면 됩니다. 엑셀이든 메모든 상관없습니다.
이게 없으면 순이익이 안 나옵니다.

광고비와 택배비는 아시면 주시고, 모르시면 빼고 계산합니다.


보내기 전에 지워 주실 것이 있습니다

구매자 이름, 연락처, 주소가 들어 있으면 그 열을 통째로 지우고 보내주세요.
계산에 쓰지 않는 정보이고, 제가 받지 않는 편이 서로 안전합니다.

주문번호, 상품명, 금액, 수수료만 있으면 됩니다.
지우는 법을 모르시겠으면 말씀해 주세요. 어느 열인지 짚어 드립니다.
```

## 가격 정보

```
패키지로 설정을 켜고 세 칸을 채운다.

── STANDARD ──
제목    한 마켓 한 달치
설명    상품별 순이익표와 적자 상품 목록을 PDF와 엑셀로 드립니다.
금액    39000

── DELUXE ──
제목    여러 마켓 합산 + 손익분기
설명    마켓별 정산서를 합산하고, 적자 상품의 본전 판매가까지 계산합니다.
금액    69000

── PREMIUM ──
제목    석 달치 추세 분석
설명    석 달을 이어 붙여 어떤 상품의 마진이 줄고 있는지 찾아 드립니다.
금액    99000

작업 기간   2일
수정 횟수   2회
```

**값을 이렇게 잡은 근거**

잘 팔리는 엑셀 양식이 20,000~48,000원이다(164건짜리가 32,000원).
사람이 대신 해주는 원가계산 대행은 80,000원에 46건이다.
대행은 양식보다 위, 8만원보다는 아래가 맞다.

크몽 수수료 약 21.7%를 빼면 39,000원은 손에 30,500원이 남는다.
주문 한 건에 우리 손은 몇 분이므로 이 값에서 적자가 나지 않는다.

## 올리기 전에 볼 것

- 기존 서비스는 심사 중이다. **절대 건드리지 않는다.**
- 등록과 편집은 PC에서만 된다. 휴대폰 크롬 데스크톱 모드로 들어간다.
- 통신판매업 신고 기준은 `kmong.md` 맨 아래 메모를 다시 읽는다.
- 메인 이미지는 기존 커버를 쓰지 말고 새로 만든다. 파는 게 다르다.
