서비스명: 오픈마켓 정산서 손익 분석 도구
카테고리: IT·프로그래밍 > 완성형 프로그램 스토어

현재 어떤 상태인지 확인 부탁드립니다.

혹시 반려된 건이라면 사유를 알려주시면 수정해서 다시 올리겠습니다.
심사가 진행 중이라면 대략 언제쯤 결과를 받을 수 있는지 알려주시면
그때까지 서비스는 그대로 두고 기다리겠습니다.

보내기 전에 먼저 볼 것
━━━━━━━━━━━━━━━━━━━━━━━━
마이크몽 → 내 서비스 에서 서비스 옆에 붙은 상태 표시를 먼저 본다.

  검수중 / 승인대기   → 아직 심사 중이다. 위 문의를 보낸다.
  반려 / 수정요청     → 이미 결과가 나왔는데 알림을 못 본 것이다.
                        사유를 눌러 읽고, 문의 대신 바로 고치면 된다.
  승인 / 판매중       → 이미 났다. swap.md 대로 가격과 설명을 한 번에 고친다.
  목록에 아예 없음    → 임시저장에서 최종 제출이 안 된 것이다.
                        임시저장 탭을 확인한다.

알림함(마이크몽 → 알림)과 가입 메일함의 스팸함도 같이 본다.
반려 안내는 앱 알림으로 오고, 며칠 지나면 뒤로 밀려서 잘 안 보인다.
