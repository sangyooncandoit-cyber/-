# 커버 이미지

`scripts/make_covers.py`가 만든다. 숫자는 `data.json`에서 읽고,
`data.json`은 검증된 계산 로직이 만든 값이라 커버에 적힌 수치와
도구가 내놓는 수치가 어긋날 수 없다.

## 규격 근거

| 용도 | 규격 | 출처 |
|---|---|---|
| 크몽 서비스 메인 | 4:3, 최소 652×488 | 크몽 고객센터 |
| 크몽 상세 이미지 | 가로 652px 이상, 세로 3000px 이하 | 크몽 고객센터 |
| Gumroad 커버 | 1280×720 | Gumroad 헬프센터 |
| Gumroad 썸네일 | 600×600 이상 | Gumroad 헬프센터 |

크몽은 메인 이미지에 텍스트를 넣을 때 상하좌우 50px 이상 여백을 권장한다.
1600×1200으로 뽑으므로 여백은 그 배수로 잡혀 있다.

## 다시 만들기

```bash
python3 scripts/make_covers.py
```

폰트(IBM Plex Sans KR / Mono woff2)를 로컬에 두고 경로를 스크립트 상단
`FONTS`에 지정해야 한다. 시스템 한국어 폰트만으로는 품질이 떨어진다.

## 색

차트 색은 흑자 `#0B7A4B` / 적자 `#C42B1C`. 라이트 모드 기준으로
색약 대비 검증을 통과한 조합이고, 색만으로 구분하지 않도록
막대 방향과 부호를 함께 쓴다.

## 대행 서비스용 (11~15)

`scripts/make_covers_daehang.py` 가 만든다. 같은 `data.json` 을 읽으므로
기존 커버와 숫자가 어긋나지 않는다.

| 파일 | 용도 |
|---|---|
| 11_표지_대행.png | 크몽 메인 이미지 |
| 12_흐름_대행.png | 보내실 것 / 받으실 것 |
| 13_상품별순이익_대행 (예시데이터).png | 리포트 표 |
| 14_본전판매가_대행 (예시데이터).png | 적자 상품과 손익분기 판매가 |
| 15_프로그램과의차이_대행.png | 프로그램 구매와의 차이 |

전부 1600×1200. 크몽 미리보기 최소 5장 조건을 채운다.

**예시 데이터가 들어간 두 장은 파일명에 그렇게 적었다.** 화면 안에도
"예시 데이터" 표시를 넣었다. 실제 판매 기록으로 오해될 여지를 남기지 않는다.

손익분기 판매가는 지어낸 값이 아니라 `data.json` 에서 역산한다.

    개당 판매가 p, 수량 q, 수수료율 r 일 때
    p·q·(1−r) − 원가 − 광고비 = 0  →  p = (원가+광고비) / (q·(1−r))

스크립트를 돌리면 계산 결과를 먼저 출력하므로 눈으로 검산할 수 있다.
