# 커버 이미지

`scripts/make_covers.py`가 만든다. 숫자는 `data.json`에서 읽고,
`data.json`은 검증된 계산 로직이 만든 값이라 커버에 적힌 수치와
도구가 내놓는 수치가 어긋날 수 없다.

## 규격 근거

| 용도 | 규격 | 출처 |
|---|---|---|
| 크몽 서비스 메인 | 4:3, 최소 652×488 | 크몽 고객센터 |
| 크몽 상세 이미지 | 가로 652px 이상, 세로 3000px 이하 | 크몽 고객센터 |
| Gumroad 커버 | 1280×720 | Gumroad 헬프센터 |
| Gumroad 썸네일 | 600×600 이상 | Gumroad 헬프센터 |

크몽은 메인 이미지에 텍스트를 넣을 때 상하좌우 50px 이상 여백을 권장한다.
1600×1200으로 뽑으므로 여백은 그 배수로 잡혀 있다.

## 다시 만들기

```bash
python3 scripts/make_covers.py
```

폰트(IBM Plex Sans KR / Mono woff2)를 로컬에 두고 경로를 스크립트 상단
`FONTS`에 지정해야 한다. 시스템 한국어 폰트만으로는 품질이 떨어진다.

## 색

차트 색은 흑자 `#0B7A4B` / 적자 `#C42B1C`. 라이트 모드 기준으로
색약 대비 검증을 통과한 조합이고, 색만으로 구분하지 않도록
막대 방향과 부호를 함께 쓴다.
