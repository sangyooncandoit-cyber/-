# 판매용 배포 파일

구매자에게 그대로 전달하는 파일. `scripts/build.py`가 만든다.

| 파일 | 용도 |
|---|---|
| 정산엑스레이.html | 정식판 — 구매자에게 전달 |
| 정산엑스레이_Lite.html | 라이트판 — 무료 배포용 |

## dist/ 와 무엇이 다른가

`dist/`는 아티팩트로 발행하는 판이고, 여기는 **디스크에서 바로 여는 판**이다.

1. **엑셀 파서를 파일 안에 넣었다.** `dist/`는 CDN에서 불러오므로
   인터넷이 끊기면 파일을 읽지 못한다. 판매 문구에 "인터넷을 끊어도
   동작합니다"라고 적었으므로, 배포판은 그게 사실이어야 한다.
2. **완전한 HTML 문서로 감쌌다.** 아티팩트는 발행 시 뼈대가 씌워지지만
   내려받은 파일은 그렇지 않다.

## 검증

오프라인(외부 요청 전면 차단) 상태에서 실제 샘플 파일로 확인했다.

| 포맷 | 결과 |
|---|---|
| 쿠팡 | 252행, 헤더 1번째 줄, 수수료 부호 보정됨, 수수료 696,388원 |
| 스마트스토어 | 253행, 헤더 3번째 줄, 보정 불필요, 수수료 420,131원 |

두 포맷 모두 매출 6,112,500원으로 일치하고 JS 오류 0건.
`scripts/test_core.js`의 검증 수치와 같다.

## 남는 외부 요청

글꼴(Google Fonts) 하나뿐이다. 인터넷이 없으면 기기의 기본 글꼴로
대체되며, 계산과 기능에는 영향이 없다.

## 라이선스

엑셀 파서는 SheetJS 0.18.5 (Apache-2.0)를 포함한다. 파일 안에 고지가 들어 있다.
