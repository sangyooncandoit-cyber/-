# 정산 엑스레이

오픈마켓 정산 엑셀을 넣으면 **상품별 실제 순이익과 적자 상품**을 찾아주는 단일 HTML 도구.

설치·계정·서버가 없다. 파일은 브라우저 안에서만 처리되고 어디로도 전송되지 않는다.
정산 파일은 매출 전체가 담긴 민감 자료라, 계정 연동을 요구하는 경쟁 서비스와
갈리는 지점이 여기다.

## 왜 마진 계산기와 다른가

무료 마진 계산기는 상품 하나의 **예상** 마진을 손으로 입력해 계산한다.
이 도구는 **실제 정산 파일** 수백~수천 행을 통째로 읽어, 반품과 광고비까지 반영한
사후 손익을 상품별로 낸다.

## 동작

| 단계 | 내용 |
|---|---|
| 1 | 정산 엑셀(.xlsx/.xls/.csv)을 끌어다 놓는다 |
| 2 | 컬럼을 자동으로 잡는다. 틀리면 직접 바꾼다 |
| 3 | 상품별 매입원가와 기간 광고비를 넣는다 |
| 4 | 상품별 순이익·마진율과 적자 상품이 나온다 |

`순이익 = 매출 − 수수료 − 원가 − 광고비`

## 까다로운 부분을 어떻게 처리하나

마켓마다 정산 파일 모양이 달라서, 컬럼 이름을 고정하면 바로 깨진다. 그래서:

- **헤더 행 탐지** — 상단에 제목·기간 줄이 붙어 있어도 진짜 헤더를 찾는다
- **컬럼 자동 매핑** — 한국어 별칭 사전으로 역할을 배정한다 (`상품명`/`등록상품명`,
  `결제금액`/`판매금액`, `수량`/`판매수량` …)
- **수수료 부호 자동 보정** — 스마트스토어는 수수료를 양수로, 쿠팡은 음수로 적는다.
  매출 부호와 비교해 규약을 판별한 뒤 맞춘다
- **수수료 다중 컬럼 합산** — 결제수수료·판매수수료·쿠폰분담금이 따로 있으면 모두 더한다
- **반품 처리** — 음수 행으로 인식해 매출·수수료·원가에서 함께 뺀다
- **지저분한 숫자** — `39,900` `(1,234)` `△500` `₩12,000` 을 모두 읽는다
- **합계행 제외** — 파일 끝에 붙는 합계/소계 줄을 상품으로 세지 않는다

## 구조

```
src/core.js              계산 로직 (DOM 없음 — 그대로 테스트된다)
src/index.template.html  UI
src/fees.json            공개 수수료율 참고 데이터
src/sample_embed.json    데모용 내장 샘플
scripts/make_sample.py   테스트용 가짜 정산 파일 생성
scripts/make_fixtures.py 검증용 fixture 생성
scripts/test_core.js     계산 검증 (34개 항목)
scripts/build.py         단일 HTML 빌드
dist/index.html          결과물
```

## 빌드와 검증

```bash
pip install pandas openpyxl
python3 scripts/make_sample.py      # 샘플 정산 파일 생성
python3 scripts/make_fixtures.py    # 검증용 fixture
node scripts/test_core.js           # 계산 검증
python3 scripts/build.py            # dist/index.html 빌드
```

검증은 도구와 **독립적으로 계산한 정답**과 대조한다. 스마트스토어형·쿠팡형 두 포맷에서
상품별 수량·매출·수수료·원가·순이익이 모두 일치해야 통과한다.

## 한계

- 부가세, 배송비, 재고 평가는 계산에 넣지 않는다. **세무 신고용이 아니라 손익 파악용**이다
- 샘플은 공개된 수수료 구조로 만든 가짜 데이터다. 실제 정산 파일로 컬럼 별칭을 보정해야 한다
- 광고비는 상품별 매출 비중으로 배분한다. 실제 집행 내역이 있으면 그쪽이 정확하다
- 브라우저에 내장된 미리보기에서는 파일 내려받기가 막혀 있어, 결과는 **표 복사**로 내보낸다
  (엑셀에 바로 붙여넣기 된다). 파일로 배포하는 버전에서는 내려받기가 동작한다
